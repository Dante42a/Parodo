# Протокол текущей приёмки

Дата: 11.10.2026. Объект: интеграционный контур без весов модели и исходных снимков.

## Подтверждено

- создан FastAPI с `/healthz`, `/readyz`, `/v1/analyze`, `/metrics`;
- ввод ограничен по MIME, размеру, декодированию и геометрии;
- без весов анализ возвращает 503, а пустой результат — `needs_review`;
- правила имеют однозначные граничные тесты и ID;
- добавлены Streamlit UI, Docker Compose, Prometheus и CI-конфигурация;
- 12 локальных автоматических тестов проходят; lint проходит;
- изображения не сохраняются API и не выводятся в логи.

## Не подтверждено

- загрузка реальных весов и полный end-to-end запуск;
- опубликованные в README метрики ML-моделей;
- независимость пациентов в сплитах;
- медицинская корректность порогов и экспертная приемка;
- сборка контейнеров и GitFlic pipeline на зарегистрированном runner;
- фактические личные коммиты и review каждого участника.

До закрытия этих пунктов демонстрируется инженерный исследовательский прототип, а не клинически валидированная система.
