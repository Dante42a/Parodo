# Сбор и подготовка данных

Статус: частично подтверждено автоматическим аудитом 11.10.2026. Ответственный: Кирилл; review: Роман.

## Содержание этапа

В репозитории проверена 251 LabelMe-аннотация: все JSON читаются, встроенных снимков нет, обнаружено 502 объекта `bone` и 107 объектов `cortical`, повторяющихся `imagePath` нет. Права на внешние датасеты и независимость пациентов ещё требуют проверки.

## Предстоящая работа

Создать паспорт каждого набора; сверить лицензии, число изображений, разметку, дубликаты и разделение по пациентам. Разделять данные до настройки преобразований; оценку на test не использовать для подбора параметров.

## Критерий завершения

Реестр данных, контрольные суммы, протокол разметки, неизменяемые train/val/test и отчёт об утечках. Артефакты проверены участником команды; ссылки и дата проверки внесены ниже.
