# Проверка качества

Статус: интеграционная проверка выполнена частично; ML-метрики не воспроизведены. Ответственный: Кирилл; review: команда.

## Содержание этапа

Планируется проверка сегментации, геометрии, правил и пользовательского сценария. Метрики из README GitHub не считаются новыми измерениями команды.

## Предстоящая работа

Выполнить независимую оценку, граничные проверки, обработку некорректного ввода и экспертную оценку ошибок.

## Критерий завершения

Протокол с версиями данных/моделей, результатами, ошибками и решением о приёмке. Артефакты проверены участником команды; ссылки и дата проверки внесены ниже.

## Свидетельства

| Артефакт / версия | Результат проверки | Автор реальной работы | Проверяющий / дата |
|---|---|---|---|
| `tests/`, `docs/acceptance_report.md` | 12 автоматических тестов; lint без ошибок | план: Кирилл | review команды ожидается |
