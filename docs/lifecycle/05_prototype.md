# Создание и обучение прототипа

Статус: программный контур реализован; end-to-end с весами не проверен. Ответственные: Даниил, Игорь, Кирилл.

## Содержание этапа

GitFlic — рабочий учебный репозиторий. Материалы GitHub переносятся выборочно после проверки происхождения и разрешений.

## Предстоящая работа

Реализовать воспроизводимый запуск, геометрию, механизм правил, объяснение и интерфейс. Каждый участник выполняет собственную содержательную задачу.

## Критерий завершения

Проверенные изменения, конфигурации, версии зависимостей, журналы запусков и инструкции воспроизведения. Артефакты проверены участником команды; ссылки и дата проверки внесены ниже.
