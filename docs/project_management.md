# Управление проектом

## Цель и критерии успеха

Цель учебного проекта — показать воспроизводимый исследовательский контур анализа ОПТГ: контролируемый ввод, сегментация, расчёт признаков, версионированные правила, объяснимый результат, визуализация и передача решения специалисту.

Критерии приёмки курса:

1. В репозитории видны семь этапов жизненного цикла и связи с артефактами.
2. Сервис запускается по инструкции; API отклоняет некорректный ввод и не формирует результат без весов.
3. Команда демонстрирует полный сценарий на разрешённом обезличенном примере.
4. Каждый участник показывает собственные коммиты и объясняет свою часть.
5. Ограничения, версии моделей, правила и действия при отказе доступны пользователю.

Клиническая эффективность и регистрация медицинского изделия не входят в объём учебного MVP.

## RACI

Обозначения: **R** — выполняет, **A** — отвечает за результат, **C** — консультирует, **I** — информируется.

| Результат | Роман | Кирилл | Даниил | Игорь |
|---|---:|---:|---:|---:|
| Требования и критерии приёмки | A/R | C | C | C |
| Данные, версии и воспроизводимость | A | R | I | I |
| Контейнеры, CI и мониторинг | A | R | C | I |
| API и интеграция модели | A | C | R | C |
| Интерфейс и визуализация | A | I | C | R |
| Тестирование полного сценария | A | R | R | R |
| Документация и защита | A/R | C | C | C |

## Backlog и спринты

### Спринт 1 — основа и прозрачность

- объединить код и документацию;
- формализовать требования, ограничения и матрицу прослеживаемости;
- зафиксировать роли, RACI и Definition of Done;
- добавить аудит аннотаций.

### Спринт 2 — интеграция

- реализовать FastAPI и версионированный контракт;
- реализовать Streamlit-интерфейс;
- добавить Docker Compose и Prometheus;
- покрыть правила и валидацию тестами.

### Спринт 3 — подтверждение и защита

- подключить фактические веса и записать контрольные суммы;
- выполнить независимую оценку без подбора по test;
- провести экспертный review ошибок;
- записать демонстрацию и провести репетицию защиты.

## Definition of Done

Задача завершена, когда есть: код или документ; автоматическая либо воспроизводимая ручная проверка; ссылка на коммит; review другим участником; обновлённая строка матрицы прослеживаемости; отсутствие персональных данных и неподтверждённых медицинских заявлений.
