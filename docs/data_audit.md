Контрольная сумма SHA-256 рассчитывается для каждого JSON и сохраняется в локальном `reports/data_manifest.json`. Сам отчёт воспроизводится скриптом и не содержит исходных снимков.

Критическое ограничение: в аннотациях нет стабильного идентификатора пациента, поэтому независимость train/val/test по пациентам подтвердить нельзя. Отсутствие повторяющихся имён файлов не исключает дубликаты изображений. До получения исходных снимков и метаданных аудит утечек считается частичным.
