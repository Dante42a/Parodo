# План проверки и приёмки

Тестирование системы ещё не выполнено. Целевые пороги и экспертная эталонная выборка требуют согласования до итогового запуска.

| ID | Проверка | Ожидаемый результат |
|---|---|---|
| T-01 | Валидный файл, повреждение, неверный формат, превышение лимита | Явное принятие/отказ без зависания |
| T-02 | Зубы и FDI на независимой разметке | mAP50/50–95, ошибки по классам, пропуски и дубликаты |
| T-03 | Кость и cortical отдельно | Dice/IoU с распределением по изображениям; слабый cortical не скрывается средним |
| T-04 | Геометрия относительно экспертных измерений | MAE, систематическая ошибка, случаи неверных ориентиров |
| T-05 | ratio на границах 0.10, 1/3, 2/3 и рядом с ними | Ровно один интервал, объяснение с ID правила |
| T-06 | NaN, infinity, отрицательное значение, длина 0, отсутствующая маска | Недостаточно данных, без уверенной категории |
| T-07 | Ввод → результат → визуальная проверка человеком | Понятны ограничения, версии и причины вывода |
| T-08 | Повтор запуска в чистом окружении | Воспроизводимость в оговорённом допуске |
| T-09 | Проверка всех заимствованных материалов | Источник, версия, лицензия, основание переноса |
| T-10 | Проверка логов и экспорта | Нет исходных изображений/идентификаторов без разрешённой необходимости |
| T-11 | Время обработки после прогрева | p50/p95, среда и размер входов зафиксированы |

Итоговую классификацию оценивать только при наличии независимых экспертных меток: precision, recall, F1, confusion matrix и анализ ложных решений. Метрики сегментации не подтверждают качество диагноза.

Шаблон протокола: дата; исполнитель; проверяющий; commit; версии моделей/данных; параметры; среда; ожидаемый результат; фактический результат; ошибки; ссылка на артефакт; решение о приёмке.
