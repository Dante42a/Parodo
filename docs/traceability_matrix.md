# Матрица прослеживаемости

Статусы отражают проверку от 11.10.2026. «Частично» означает, что программный контур подтверждён, но модель/данные/экспертная оценка ещё не проверены end-to-end.

| Потребность | Требование | Источник данных/знаний | Компонент | Проверка | Действие при отказе | Статус и свидетельство |
|---|---|---|---|---|---|---|
| Корректный ввод | FR-01 | Паспорт форматов | `src/api/service.py` | T-01 повреждённые и допустимые файлы | HTTP 422 с причиной | подтверждено: `tests/test_api_scenarios.py` (неверный формат, превышение размера, файл на границе лимита), `tests/test_input_validation.py`; выполняется в CI |
| Найти зубы | FR-02 | AKUDENTAL, лицензия проверить | `stage1_segment.py` | T-02 mAP, FDI | Проверка человеком | не проверено: нет весов и снимков |
| Найти кость | FR-03 | 251 JSON-аннотация bone/cortical | `stage1_segment.py` | T-03 Dice/IoU | Не продолжать при плохой маске | частично: `docs/data_audit.md`; ML-метрики не воспроизведены |
| Оценить геометрию | FR-04 | Маски, экспертные измерения | `stage2_measure.py` | T-04 MAE/ошибки ориентиров | Недостаточно данных | код есть; сравнение с ручными измерениями ожидается |
| Прозрачный вывод | FR-05, FR-06 | KB-01…07 | `stage2_classify.py`, API | T-05 границы и цепочки | Показать статус/ID правила | частично: граничные тесты и `rule_id` подтверждены; экспертный review ожидается |
| Контроль неопределённости | FR-07 | Паспорт качества | правила и API | T-06 отсутствующие/невалидные факты | `needs_review`, HTTP 503 | пподтверждено для пустого результата, отсутствующих весов и недоступной модели (загрузка, сбой загрузки, занятость): `tests/test_api_scenarios.py`, `tests/test_model_loading.py` |
