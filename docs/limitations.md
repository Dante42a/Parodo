# Ограничения и риски

| ID | Ограничение / неопределённость | Последствие | План проверки / мера |
|---|---|---|---|
| L-01 | ОПТГ — проекционное изображение | Геометрическая оценка зависит от искажений | Экспертная проверка, не заявлять трёхмерную точность |
| L-02 | Ориентиры ЦЭГ могут определяться эвристически | Систематическая ошибка ratio | Аудит кода и сравнение с ручными ориентирами |
| L-03 | Источник сообщает слабую сегментацию cortical | Риск неправильной интерпретации типа заболевания | Исключить диагностическое использование до валидации |
| L-04 | README содержит разные числа ручных аннотаций | Неясен фактический объём выборки | Сверить manifest и контрольные суммы |
| L-05 | Независимость пациентов и дубликаты не проверены | Завышенная оценка качества | Аудит утечек и пациентских групп |
| L-06 | Метрики GitHub не воспроизведены | Нельзя заявлять их как результаты учебной команды | Отдельный запуск с версиями и отчётом |
| L-07 | Пороговые правила не подтверждены экспертом | Категории не равнозначны диагнозу | Экспертная проверка базы знаний |
| L-08 | Права на код, веса и ручную разметку не проверены | Неправомерный перенос материалов | Лицензионный аудит до переноса |
| L-09 | Нет официальных материалов LMS | Названия этапов, роли и критерии могут отличаться | Сверить документы с LMS |
| L-10 | Доступ на запись GitFlic не подтверждён | Пакет пока локальный | Авторизация и проверка прав |

Учебная демонстрация не доказывает клиническую эффективность или юридическую готовность к эксплуатации.
