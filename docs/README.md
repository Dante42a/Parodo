# Parodo — документация учебного проекта

Дата актуализации: 11.10.2026. Статус: рабочая документация командного проекта.
Тема: интеллектуальная система анализа тканей пародонта по ОПТГ с использованием сегментации изображений и формализованных правил.

Документация хранится рядом с кодом и связывает требования курса с реализацией, проверками и ответственными ролями. Статус «подтверждено» используется только при наличии воспроизводимого свидетельства.
