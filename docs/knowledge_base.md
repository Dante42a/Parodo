# База знаний — проект спецификации

Статус: гипотезы и эвристики для проверки. Ни одно медицинское правило не утверждено специалистом. Текущий код GitHub ещё не сопоставлен с этой спецификацией. Предложенные правила не используются для клинических решений.

## Словарь фактов

| Факт | Значение / единицы | Проверка пригодности |
|---|---|---|
| tooth_id | FDI, идентификатор экземпляра | допустимый класс, отсутствие неоднозначного дубликата |
| root_length | длина корня в координатах изображения | конечное положительное число, метод и ориентиры задокументированы |
| bone_loss | оценка расстояния убыли в той же системе координат | конечное число; отрицательные значения и выбросы разобрать отдельно |
| bone_loss_ratio | bone_loss / root_length, безразмерное | одинаковые единицы; значения вне [0,1] требуют проверки, без молчаливого обрезания |
| cortical_coverage | доля покрытия, определение уточнить | недоступный/невалидированный признак не считается отсутствием пластинки |
| quality_ok | результат проверки входа и масок | критерии и пороги ещё требуется выбрать |

## Правила

Приоритет: сначала пригодность и конфликт, затем только разрешённые исследовательские интервалы. Все правила ниже имеют статус «предложено».

| ID | Условие | Результат | Основание / что проверить |
|---|---|---|---|
| KB-01 | Некорректные факты, некачественные маски или root_length ≤ 0 | Недостаточно данных; причина; проверка человеком | Требование FR-07; критерии качества уточнить |
| KB-02 | Валидный ratio < 0.10 | Исследовательская группа A | Эвристика README GitHub; медицинское значение не подтверждено |
| KB-03 | 0.10 ≤ ratio < 1/3 | Исследовательская группа B | Нижняя граница 0.10 — предлагаемое устранение пересечения с A |
| KB-04 | 1/3 ≤ ratio < 2/3 | Исследовательская группа C | Границы равенства предложены для однозначности |
| KB-05 | 2/3 ≤ ratio ≤ 1 | Исследовательская группа D | Исходный README оставляет неоднозначность равенства; нужна проверка |
| KB-06 | cortical отсутствует или невалидирован | Не выводить тип заболевания по cortical | Ограничение исходного README и FR-07 |
| KB-07 | Есть конфликт выводов | Неопределённый результат и причины | Предложенный механизм контроля |

Названия «норма», «пародонтит», «пародонтоз» из исходного проекта не переносятся в утверждённые правила. Ratio и cortical сами по себе здесь не признаны достаточным основанием для диагноза.

## Карточка подтверждения правила

ID; формулировка; первоисточник и страница; эксперт и дата; область применимости; противопоказания/исключения; версия; тесты; решение о разрешении использования. Все поля пока требуют заполнения.

Пример объяснения: «ratio=0.28; группа B по KB-03; геометрия v…; модель v…; требуется проверка специалистом». Это пример формата, не результат реального запуска.
