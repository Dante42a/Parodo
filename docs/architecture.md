# Архитектура интеграционного MVP

```text
Streamlit UI → FastAPI /v1/analyze → контроль формата/размера
                                   → семантическая сегментация кости
                                   → YOLO-сегментация зубов
                                   → геометрические признаки
                                   → правила research-rules-v1
                                   → объяснение + overlay + статус review
                     ↘ /metrics → Prometheus
```

## Контракты

- Ввод: PNG/JPEG/WebP, до 20 МБ по умолчанию, не менее 64×64 пикселей.
- Вывод: request ID, версии модели и правил, статус, исследовательская категория, признаки по зубам, ID правила, overlay и обязательное предупреждение.
- Неготовность: без весов API возвращает HTTP 503; некорректный ввод — HTTP 422; отсутствие измерений — `needs_review`/`InsufficientData`.
- Данные изображения не записываются приложением на диск и не включаются в логи.

## Граница безопасности

MVP не формирует клиническое заключение и не заменяет врача. Результат требует проверки человеком. Показатель cortical не используется для классификации до подтверждения качества. Система должна прекращать автоматический вывод при непригодных признаках.
