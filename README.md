# Parodo — анализ тканей пародонта по ОПТГ

Исследовательская система для автоматического выявления заболеваний пародонта на панорамных рентгеновских снимках зубов (ортопантомограммах, ОПТГ).

> ⚠️ Система **не является** медицинским диагностическим инструментом. Результаты требуют интерпретации врача-стоматолога.

## Что делает система

Принимает ОПТГ-снимок, затем:

1. детектирует зубы с номерами по FDI;
2. сегментирует альвеолярную кость и кортикальную пластинку;
3. для каждого зуба измеряет убыль кости относительно длины корня (`bone_loss_ratio`);
4. ставит диагноз и степень тяжести по правилам.

### Диагностические правила

| Диагноз | Целевой признак на снимке |
|---------|---------------------------|
| Норма | Убыль кости < 10 % длины корня |
| Пародонтит | Кортикальная пластинка отсутствует (локальный / генерализованный) |
| Пародонтоз | Равномерная убыль кости при сохранённой кортикальной пластинке |

Степень тяжести по `bone_loss_ratio = потеря_кости / длина_корня`: лёгкая < 1/3, средняя < 2/3, тяжёлая > 2/3 корня.

**Текущее состояние:** классификатор использует только `bone_loss_ratio` (Норма / Пародонтит). Разделение пародонтита и пародонтоза по кортикальной пластинке реализовано, но отключено: пластинка размечена лишь на 60 снимках и сегментируется ненадёжно (Dice ≤ 0,12). Подробности в [src/pipeline/stage2_classify.py](src/pipeline/stage2_classify.py).

## Архитектура — двухмодельный пайплайн

```
ОПТГ-снимок
    │
    ├─► [YOLOv8m-seg]  ← AKUDENTAL (333 снимка, 35 FDI-классов)
    │       └─ маски зубов + FDI-метки
    │
    └─► [DeepLabV3+]   ← ручная разметка bone/cortical (251 снимок)
            ├─ маска альвеолярной кости
            └─ маска кортикальной пластинки
                │
                ▼
    [Этап 2: геометрия + классификация]
            ├─ bone_loss_ratio на каждый зуб
            ├─ cortical_coverage
            └─ диагноз + степень тяжести
```

## Результаты

### Инстанс-сегментация зубов (AKUDENTAL, val — 49 снимков)

| Модель | Box mAP50 | Box mAP50-95 | Mask mAP50 | Mask mAP50-95 |
|--------|-----------|--------------|------------|---------------|
| **YOLOv8m-seg** | **0.970** | **0.722** | **0.960** | **0.665** |

### Семантическая сегментация кости и кортикальной пластинки (test — 38 снимков)

Все 5 моделей обучены на едином bone-сплите (175 train / 38 val / 38 test, стратификация по наличию cortical) с одинаковыми аугментациями.

| Модель | Backbone | mIoU | Dice_tooth | Dice_bone | Dice_cortical | FPS |
|--------|----------|------|-----------|-----------|---------------|-----|
| **DeepLabV3+** ✅ в пайплайне | ResNet-101 | **0.616** | 0.809 | **0.920** | 0.003 | **40.0** |
| U-Net | ResNet-50 | 0.616 | 0.785 | 0.896 | 0.116 | 36.1 |
| U-Net++ | EfficientNet-B4 | 0.605 | 0.789 | 0.899 | 0.055 | 18.3 |
| SegFormer | MiT-B3 | 0.605 | 0.762 | 0.887 | **0.124** | 19.2 |
| Swin-UNet | Swin-B (IN-22k) | 0.570 | 0.733 | 0.867 | 0.066 | 20.7 |

`Dice_cortical` низкий у всех моделей: класс тонкий и редкий (60 размеченных снимков, 42 в train). mIoU занижен за счёт усреднения с почти нулевым cortical.

## Быстрый старт

Разработка велась на Python 3.12 с CUDA GPU.

```bash
pip install -r requirements.txt

# Зубы: AKUDENTAL → YOLOv8m-seg
python scripts/prepare_akudental.py          # требует клонированного репозитория AKUDENTAL
python scripts/train_yolo_akudental.py       # → checkpoints/yolov8/teeth_akudental/weights/best.pt

# Кость/пластинка: данные и сплиты
python scripts/download_dentex.py
python scripts/preprocess.py
python scripts/create_splits.py

# Проверка пайплайна обучения (2 батча)
python scripts/train.py --config configs/unet.yaml --fast_dev_run

# Обучение (сравнение архитектур)
python scripts/train.py --config configs/deeplabv3plus.yaml
#   также: unet.yaml, unetpp.yaml, segformer.yaml, swin_unet_bone.yaml
#   продолжить: --resume checkpoints/<name>.ckpt

# Оценка и сравнение
python scripts/evaluate.py --config configs/deeplabv3plus.yaml --checkpoint checkpoints/<name>.ckpt
python scripts/compare_models.py
mlflow ui --port 5000

# Приложение → http://localhost:7860
python app/app.py \
  --model checkpoints/<deeplabv3plus>.ckpt \
  --yolo  checkpoints/yolov8/teeth_akudental/weights/best.pt
```

## Ограничения и дальнейшая работа

- ОПТГ — двумерная проекция 3D-анатомии, поэтому убыль кости может занижаться или завышаться.
- Положение цементно-эмалевой границы (ЦЭГ) берётся анатомическим приближением (40/60 % высоты зуба), а не детектируется напрямую.
- Кортикальная пластинка сегментируется ненадёжно, и полная логика диагноза (пародонтит / пародонтоз) отключена. Нужно больше разметки.
- Автотестов пока нет.
- Клиническая валидация на реальных данных не проводилась.
